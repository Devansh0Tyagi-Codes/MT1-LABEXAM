Employee Task Management System

A full-stack Node.js and Express.js web application built for the MT1 Lab Examination demonstrating modular architecture, HTTP/FS static serving, and RESTful APIs.

Node.js HTTP Module FS Module Static Serving Express.js REST API In-Memory Array Storage

Core Features & Architecture

⚙

HTTP & Routing (Part A)

Built-in Node.js http module server on port 3000 handling welcome routing, JSON data retrieval, error handling, and task additions.

📄

Static File Serving (FS)

Built-in Node.js fs module reading and streaming static files (index.html) directly when navigating to /home.

🚀

Express.js REST API (Part B)

Dedicated Express server on port 4000 providing full CRUD operations: GET all tasks, GET by ID, POST new task, PUT update, and DELETE.
